API & Widget Documentation

Free, structured access to every promise, budget, fraud case, executive order, and appointment NGScorecard tracks across Nigeria's federal and state administrations — as a JSON API and as a drop-in embeddable widget. No cost, self-serve, no waiting on a human.

1Quick start

Get a free key, then call any endpoint with it. That's the whole flow — no signup form, no approval wait.

Try it right now: 
# 1. Get a key
curl -X POST https://ngscorecard.com/api/v1/keys \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com"}'

# → { "key": "ngs_live_...", "tier": "free", "rateLimit": "60 requests/minute" }

# 2. Use it
curl https://ngscorecard.com/api/v1/tinubu/promises \
  -H "X-API-Key: ngs_live_..."

2Authentication & rate limits

Every data endpoint requires an X-API-Key header. Keys are free, self-serve, and tied to an email (requesting a key again with the same email returns your existing one, so you can't accidentally pile up duplicates).

TierRate limitAuth
Free (current)60 requests/minute per keyX-API-Key header
Widget summary30 requests/minute per caller IPnone — public, CORS-open

Exceeding the limit returns 429 with a JSON error body. Missing or invalid keys return 401. Requesting an unknown administration key returns 400 (or 404 for the widget endpoint).

3Endpoints

Presidents and governors are separate lists, each with their own valid :admin keys (e.g. tinubu is a president, otti and ododo are governors) — GET /api/v1/presidents for the 5 federal presidents, GET /api/v1/governors for the 36 state governors. Every other data route takes either kind of key and follows the same shape: /api/v1/:admin/:category.

MethodPathReturns
GET/api/v1/presidentsThe 5 federal presidents and their :admin keys
GET/api/v1/governorsThe 36 state governors and their :admin keys
GET/api/v1/:admin/promisesCampaign promises, status, and sourcing
GET/api/v1/:admin/inheritedInherited problems and their resolution status
GET/api/v1/:admin/fraudFraud allegations, amounts, and outcomes
GET/api/v1/:admin/ordersExecutive orders and directives
GET/api/v1/:admin/ministersMinisters/commissioners and performance notes
GET/api/v1/:admin/billsLegislation (federal administrations only)
GET/api/v1/:admin/appointmentsKey appointments across government
GET/api/v1/:admin/judgmentsCourt judgments and compliance
GET/api/v1/:admin/budgetAnnual budgets, revenue, and debt service (see note below)
GET/api/v1/:admin/governorsHistorical state governors listed under a president's own profile — not the same list as GET /api/v1/governors above (federal administrations only)
GET/api/v1/:admin/indicatorsTracked economic/performance indicators over time
POST/api/v1/keysIssue (or retrieve) a free API key for an email

On budget data: where a figure isn't publicly reported anywhere, the field is null — never a guessed number. A null means "not published," not "zero."

4Embeddable widget

Drop a live, self-updating promise-tracking bar into any page. No API key needed — it's public and CORS-open by design.

<div data-ngscorecard-admin="tinubu"></div>
<script src="https://ngscorecard.com/widget.js" async></script>

Or, for a single widget, skip the <div> and put the admin key directly on the script tag:

<script src="https://ngscorecard.com/widget.js" data-ngscorecard-admin="tinubu" async></script>

6Stability & deprecation

This API is public infrastructure. Downstream users shouldn't be broken without warning.

  • Additive changes are not breaking. New fields on a response, new endpoints, and new optional parameters can land in v1 at any time — write clients that ignore fields they don't recognise.
  • Breaking changes get a new version. Removing or renaming a field, changing a type, or changing the meaning of a value happens under /api/v2, never in place.
  • Old versions stay up for at least 12 months after a successor ships.
  • Sunsets are announced, not silent — in this page's change history, in the GET /api/v1 index response, and via a Sunset HTTP header (RFC 8594) on the affected endpoints for the whole deprecation window.

Nothing is deprecated today. The dataset and its licence are covered separately in the methodology and DATA-LICENSE.md.
